# Cleanee

Windows 向けのファイルクリーニング & PC メンテナンスアプリです。CleanMyMac の主要機能を Windows で再現しています。
Electron + React + TypeScript で構築しています。

## 機能

| カテゴリ | モジュール | 内容 |
| --- | --- | --- |
| — | **スマートスキャン** | ジャンク検出・Defender の状態確認・メモリ/DNS の最適化をワンクリックで実行 |
| クリーンアップ | **システムジャンク** | ユーザー/システム一時ファイル、ブラウザキャッシュ、アプリキャッシュ、GPU シェーダーキャッシュ、ログ、クラッシュダンプ、Windows Update キャッシュ、開発ツールのキャッシュ、ごみ箱 |
| | **プライバシー** | Chrome / Edge / Brave / Vivaldi / Opera / Firefox の履歴・Cookie・セッション・フォーム履歴、最近使ったファイル、「ファイル名を指定して実行」の履歴、クリップボード、DNS キャッシュ |
| 保護 | **マルウェア対策** | Microsoft Defender と連携（保護状態、定義の更新、クイック/フルスキャン、検出履歴、脅威の削除） |
| スピード | **最適化** | スタートアップアプリの有効/無効切り替え（タスクマネージャーと同じ仕組み）、メモリ解放 |
| | **メンテナンス** | メモリ解放、DNS 消去、サムネイル/アイコンキャッシュ再構築、エクスプローラー再起動、復元ポイント作成、TRIM、sfc、DISM、コンポーネントストア整理、chkdsk |
| アプリケーション | **アンインストール** | インストール済みアプリの一覧・検索・並べ替え、アンインストール後の残りファイル検出 |
| | **アップデート** | winget を使ったアプリの一括アップデート |
| ファイル | **スペースレンズ** | ドライブ/フォルダのサイズをツリーマップで可視化、ドリルダウン、ごみ箱へ移動 |
| | **大容量・古いファイル** | 大きなファイルを種類・最終使用日で絞り込み |
| | **重複ファイル** | ハッシュで内容が完全一致するファイルを検出し、オリジナルを残して自動選択 |

### デザイン

- macOS の Liquid Glass を参考にした、半透明のガラス素材・グループ化リスト・カプセル型ボタン
- ライト / ダーク / システム連動のテーマ（設定 → 外観）
- フォントは Rakumanual と同じ Inter Variable + Noto Sans JP Variable を同梱（Windows でも同じ見た目）
- 色は macOS のシステムカラーを使用し、表示中の機能の色がウィンドウのアクセントになります

### 便利機能

- **キーボード**: Ctrl+1〜9 で機能切り替え、Ctrl+, で設定、F1 でヘルプ
- **前回の画面を記憶**: 次回起動時は最後に開いていた機能から始まります

- **ヘルプ**: 各画面の説明は右上の「ヘルプ」ボタン（F1）にまとめています
- **設定**: サイドバー上部の歯車から。通知領域への常駐、Windows 起動時の自動開始、アニメーション（自動 / オン / オフ）、空き容量低下の通知、一時ファイルの保持期間、除外フォルダ
- **トレイメニュー**: ウィンドウを閉じても常駐し、スマートスキャン・メモリ解放・空き容量の確認ができます
- **個別除外**: システムジャンクのカテゴリを開くと、ファイル単位で削除対象から外せます
- **累計表示**: これまでに解放した容量とクリーンアップ回数を記録します

### 安全設計

- 一時ファイルは保持期間（既定 24 時間）以内のもの、ログは 7 日以内のものを対象外にします
- 使用中のファイルはスキップします（削除失敗件数を通知）
- ユーザーが選ぶファイル（大容量・重複・スペースレンズ・残りファイル）は **ごみ箱へ移動** するため復元できます
- 保存済みパスワード・ブックマークは削除しません
- シンボリックリンク/ジャンクションはたどりません
- 管理者権限は任意です。必要な項目だけ「管理者として再起動」または UAC で実行します

## 開発

```bash
npm install
```

UI だけをブラウザで確認（デモデータ）:

```bash
npm run dev
```

Electron で起動（Windows 以外ではデモモードになり、実ファイルには一切触れません）:

```bash
npm run electron:dev
```

## アイコン

`scripts/icon/cleanee-lime.png`（原画）からアイコン一式を生成します（macOS のみ）。

```bash
npm run icons:build
```

`build/icons/` に `Cleanee.ico`（exe・インストーラー用）、`Cleanee.icns`、各サイズの PNG が出力されます。

## Windows 用ビルド

```bash
npm run dist:win
```

`release/` に以下が出力されます。macOS からのクロスビルドにも対応しています。

- `Cleanee-Setup-<version>.exe` — インストーラー（インストール先の変更可、ユーザー単位）
- `Cleanee-Portable-<version>.exe` — インストール不要のポータブル版

コード署名はしていないため、初回起動時に SmartScreen の警告が表示されることがあります（「詳細情報」→「実行」）。

## 構成

```
electron/
  main.cjs          ウィンドウ生成と IPC
  preload.cjs       レンダラーへの安全なブリッジ
  lib/
    junk.cjs        システムジャンクのスキャン/削除
    privacy.cjs     プライバシー項目
    startup.cjs     スタートアップ項目 (レジストリ / スタートアップフォルダ)
    apps.cjs        インストール済みアプリとアンインストール
    files.cjs       大容量ファイル・重複ファイル・スペースレンズ
    system.cjs      システム情報・メンテナンス・Defender・winget
    settings.cjs    設定と累計統計の保存
    util.cjs        ファイル走査・PowerShell 実行などの共通処理
src/
  api/              IPC ラッパーとデモ用モック
  pages/            各モジュールの画面
  help.ts           ヘルプパネルの説明文
  components/       共通 UI（オーブ、スキャンボタン、モーダル、トースト…）
  styles.css        デザインシステム
build/icons/        アプリアイコン（npm run icons:build で生成）
scripts/            アイコン生成スクリプト
```
